# Learn AI Illustration with Phoebe

Six 45-minute sessions on art-directing a model instead of prompting one: where control
actually lives, style written down, composition with a zone reserved for type, why every
character of lettering is set by hand, consistency as a pipeline, and when to say no.

**Live site:** https://phoebefu6.github.io/learn-ai-illustration-with-phoebe/

| # | Session | Signature thing |
|---|---|---|
| 1 | Where control lives | The generation stack as a control surface: which knobs bind, which persuade |
| 2 | Style DNA, written down | A style described in words that outlive the person who wrote them |
| 3 | Composition and the type zone | Subject, light, ratio, and the empty third that type will own |
| 4 | The lettering law | Why models cannot spell, on mechanism; the brief bench |
| 5 | Consistency is a pipeline | Seeds at 99%, style references, the Edit Model, LoRA's cost |
| 6 | When it earns its place | The trust evidence and the click evidence side by side |

The bench in session 4 (`assets/il-live.js`) reads an illustration brief and counts, in the
text, the things a generator cannot be told twice: concrete anchors, style words and the
pairs among them that contradict, characters of lettering requested, and whether a type zone
was reserved. It measures the brief, not the image, and says so.

This repository ships **no generated raster image**. Every diagram is hand-authored SVG;
session 4 explains why on mechanism.

Every fact, its verification tier and the bench's honest limits:
`materials/official-course-map.md`.

Static HTML, CSS and JS. No build step. by Phoebe Fu.
